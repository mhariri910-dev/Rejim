# رجيمات

تطبيق خطط غذائية يوم بيوم، بالعربية، يعمل بلا إنترنت.
٢٦ نظامًا غذائيًا، متابعة وزن ومحيط خصر، سلسلة التزام وتقويم شهري، وبطاقة «الآن» تعرض وجبة الوقت الحالي.

---

## ما في هذا المستودع

| المسار | ما هو |
|---|---|
| `index.html` | التطبيق كاملًا في ملف واحد — هذا هو المصدر الوحيد |
| `manifest.webmanifest` · `sw.js` · `icon-*.png` | ملفات تثبيت التطبيق والعمل بلا إنترنت |
| `android/` | مشروع أندرويد يغلّف الصفحة نفسها |
| `.github/workflows/build-apk.yml` | يبني ملف APK تلقائيًا عند كل تحديث |

**الصفحة موجودة مرة واحدة فقط.** عند البناء تُنسخ تلقائيًا إلى `android/app/src/main/assets/`، فلا تحتاج أن تحدّث نسختين.

---

## نسخة الويب

### تشغيل GitHub Pages

1. **Settings** ← **Pages**
2. تحت **Source** اختر **Deploy from a branch**
3. الفرع `main` والمجلد `/ (root)` ← **Save**
4. بعد دقيقة يصبح التطبيق على:
   `https://mhariri910-dev.github.io/Rejim/`

### التثبيت على الجوال

افتح الرابط في **كروم** ← قائمة ⋮ ← **تثبيت التطبيق**.
تظهر أيقونة «رجيمات» بين تطبيقاتك، ويفتح بملء الشاشة ويعمل بلا إنترنت.

---

## نسخة الأندرويد (APK)

### الحصول على الملف

1. تبويب **Actions** ← مهمة **Build APK**
2. انتظر ظهور ✅ (٣ إلى ٥ دقائق)
3. افتح المهمة ← قسم **Artifacts** ← نزّل **Rejim-APK**
4. فكّ الضغط وثبّت `app-debug.apk`

### ما يميّزها

- **لا تطلب أي إذن** — لا إنترنت ولا موقع ولا جهات اتصال. افحص ذلك: الإعدادات ← التطبيقات ← رجيمات ← الأذونات.
- **البيانات تبقى بين التحديثات** — تُحمَّل الصفحة عبر `WebViewAssetLoader` من أصل ثابت لا عبر `file://`.
- **زر الرجوع** يغلق النافذة المفتوحة أولًا ثم يخرج.

### تنبيه متوقّع

قد يصف مضاد الفيروسات الملف بأنه «مشبوه». هذا إنذار كاذب سببه التثبيت اليدوي وتوقيع التطوير وانعدام السمعة في قواعد البيانات. تطبيق بلا إذن إنترنت لا يستطيع إرسال شيء إلى أي جهة.

## المزامنة السحابية

اختيارية، وتحتاج مشروع Firebase مجانيًا. دليل الإعداد بالعربية داخل التطبيق نفسه: بطاقة **المزامنة السحابية** ← **كيف أحصل عليها؟**

**تعمل في:** نسخة الويب على GitHub Pages في كروم.
**لا تعمل في:** تطبيق الأندرويد (غوغل تمنع تسجيل الدخول داخل WebView)، ولا عند فتح الملف من مجلد التنزيلات.

البديل في كل الحالات: قسم **حساب** ← **نسخة احتياطية** ينزّل ملفًا فيه كل بياناتك، و**استعادة** يُرجعه على أي جهاز.

## الأنظمة الغذائية

**٢١ نظامًا أصليًا** من إعداد مختصين — لم تُمَسّ ولم يُعدَّل فيها حرف.

**٥ أنظمة مضافة** بمساعدة الذكاء الاصطناعي، كل منها يحمل في وصفه تنبيهًا يميّزه:

| النظام | الأيام | المرجع |
|---|---|---|
| حمية البحر المتوسط | ٧ | مراجعة جامعة هارفارد |
| رجيم الكربوهيدرات — نسخة ألمانيا | ١٤ | أطعمة من ليدل وألدي والمحال العربية |
| نظام الكيتو | ٧ | نِسب مراجعة هارفارد مع موانع الاستعمال |
| رجيم ألماني سريع | ١٤ | القواعد العشر للجمعية الألمانية للتغذية (DGE) |
| برنامج مكثّف — ثمانية أسابيع | ٥٦ | نحو ١٤٠٠ سعرة وبروتين عالٍ |

### شارات التصنيف

بجانب اسم كل نظام شارة تقيّمه، والضغط عليها يشرح السبب:

- 🟢 **دليل قوي** — مدعوم بدراسات واسعة
- 🔵 **متوازن** — ثلاث وجبات وهدف واقعي
- 🟡 **مقيّد — انتبه** — يمنع مجموعات غذائية أو يخفض السعرات كثيرًا
- 🔴 **وعد غير واقعي** — الوزن الموعود أسرع مما يُخسر دهنًا

التصنيف طبقة عرض فقط ولا يغيّر أي نظام.

## تنبيه صحي

هذا التطبيق أداة متابعة، وليس بديلًا عن استشارة طبيب أو اختصاصي تغذية.
استشر طبيبك قبل أي نظام إن كنت تتناول دواءً مزمنًا، أو لديك مرض كلى أو كبد أو قلب أو سكري، أو كنت حاملًا أو مرضعًا أو دون الثامنة عشرة.

## التطوير

التطبيق ملف واحد بلا أي مكتبة خارجية ولا خطوة بناء. عدّل `index.html` وارفعه، فتتحدّث نسخة الويب فورًا ويُبنى APK جديد تلقائيًا.

مع كل إصدار جديد، ارفع `versionCode` و`versionName` في `android/app/build.gradle.kts`.
